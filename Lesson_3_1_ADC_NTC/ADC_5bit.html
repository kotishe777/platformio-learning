Як 5-бітний ADC вимірює напругу

Ідеальний SAR ADC • діапазон 0–3,2 В • вхідна напруга 2,13 В

Навчальна модель з округленням униз: код визначає інтервал напруги. Шум, нелінійність та інші апаратні похибки поки не враховуємо. Це пояснення принципу, а не налаштування 5-бітного режиму ESP32.

1. Що означають 5 бітів

Результат містить п’ять двійкових цифр: b₄ b₃ b₂ b₁ b₀. Кожна може бути 0 або 1.

Кількість кодів = 2⁵ = 32

Нумерація починається з нуля: 00000₂ = 0, а 11111₂ = 31.

32 можливі результати, але найбільший код — 31. Код 32 потребував би вже шести бітів.

2. Яку напругу представляє один крок

q = Vrange / 2ᴺ = 3,2 / 32 = 0,1 В = 100 мВ

q — ширина одного інтервалу квантування, тобто один LSB у вольтах. За нашою моделлю:

Напруга VinКод
0 ≤ Vin < 0,1 В0
0,1 ≤ Vin < 0,2 В1
2,0 ≤ Vin < 2,1 В20
2,1 ≤ Vin < 2,2 В21
3,1 ≤ Vin < 3,2 В31

2,13 В потрапляє в інтервал коду 21. Далі простежимо, як SAR знаходить цей результат.

3. Спочатку ADC бере вибірку

  1. Внутрішній ключ замикається: невеликий конденсатор заряджається від входу до напруги, близької до 2,13 В.
  2. На заряджання виділяється час вибірки — sampling time.
  3. Ключ розмикається, і конденсатор утримує напругу.
  4. ADC визначає код утримуваної вибірки.

Якщо зовнішній сигнал після цього зміниться, поточне перетворення все одно стосуватиметься взятої вибірки. Високоомне джерело заряджає конденсатор повільніше; надто короткий час вибірки може спричинити похибку.

4. Кожен біт має вагу

БітВага в кодіВага напруги
b₄ — старший161,6 В
b₃80,8 В
b₂40,4 В
b₁20,2 В
b₀ — молодший10,1 В

Внутрішній DAC створює пробну напругу з пробного коду. Компаратор порівнює її з напругою вибірки. SAR — регістр послідовного наближення — перевіряє біти від старшого до молодшого.

Якщо пробна напруга не перевищує вхідну — залишаємо пробний біт 1. Якщо перевищує — скидаємо його в 0.

5. П’ять послідовних порівнянь

КрокПробний кодDACПорівнянняРішення
110000₂ = 161,6 В2,13 ≥ 1,6b₄ = 1
211000₂ = 242,4 В2,13 < 2,4b₃ = 0
310100₂ = 202,0 В2,13 ≥ 2,0b₂ = 1
410110₂ = 222,2 В2,13 < 2,2b₁ = 0
510101₂ = 212,1 В2,13 ≥ 2,1b₀ = 1

Крок 1: 1,6 В підходить. Залишається верхня половина шкали: 1,6–3,2 В.

Крок 2: 2,4 В забагато. Інтервал звужується до 1,6–2,4 В.

Крок 3: 2,0 В підходить. Тепер шукаємо в межах 2,0–2,4 В.

Крок 4: 2,2 В забагато. Залишається 2,0–2,2 В.

Крок 5: 2,1 В підходить. Остаточний інтервал: 2,1 ≤ Vin < 2,2 В.

Це п’ять рішень для п’яти бітів одного вимірювання. Повний час вимірювання також включає вибірку та службові етапи.

6. Що отримує програма

10101₂ = 16 + 4 + 1 = 21

Програма отримує цілий raw-код 21. Напругу вона обчислює окремо.

Оцінка за нижньою межею: V̂ = Dq = 21 × 0,1 = 2,10 В
Похибка: 2,10 − 2,13 = −0,03 В = −30 мВ

2,11 В, 2,13 В та 2,19 В дають однаковий код 21. Відновити точну початкову напругу з цього коду неможливо.

Якщо представляти інтервал його серединою:

V̂center = (D + 0,5)q = 21,5 × 0,1 = 2,15 В

Для цієї оцінки ідеальна похибка квантування в межах шкали не перевищує ±q/2, тобто ±50 мВ. Реальний ADC додатково має шум та інші похибки.

Ширину кроку тут визначаємо через 32 інтервали. Масштабування коду через 31 так, щоб код 31 відповідав рівно 3,2 В, було б іншою моделлю оцінювання.

7. Перевір себе

За тією самою моделлю визнач код для 0,75 В, 1,60 В та 3,05 В. Поясни, чому 2,13 В і 2,19 В дають однаковий результат.

Показати відповіді

0,75 В → 7 → 00111₂.
1,60 В → 16 → 10000₂.
3,05 В → 30 → 11110₂.

2,13 В і 2,19 В належать одному інтервалу 2,1–2,2 В, тому обидві напруги дають код 21.

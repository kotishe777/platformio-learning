# 00 — Перший запуск ESP-IDF

## Мета прикладу

Мета: побачити точку входу `app_main()`, логування та затримку задачі без GPIO.
Ціль: ESP32-S3 DevKitC-1 / N16R8; API ESP-IDF 5.5.x, C++, без Arduino і PlatformIO.
`sdkconfig.defaults` задає 16 MB Flash та вимкнену PSRAM; приклад її не потребує.

## Схема підключення

Плата → USB-кабель з передаванням даних → ПК. Для стандартної UART0-консолі
використовуйте роз'єм USB-to-UART плати. Зовнішні компоненти не потрібні.

## Нові функції ESP-IDF та їхні параметри

| Функція або макрос | Призначення, аргументи та результат |
|---|---|
| `ESP_LOGI(tag, format, ...)` | Тег джерела, printf-подібний формат і його значення; макрос друкує лог рівня Info з префіксом. |
| `vTaskDelay(ticks)` | Блокує поточну задачу на задану кількість RTOS ticks; нічого не повертає. |

`constexpr` задає константи часу компіляції; `extern "C"` зберігає ім'я точки входу для стартового коду ESP-IDF. `pdMS_TO_TICKS(ms)` переводить ms у ticks відповідно до `CONFIG_FREERTOS_HZ`.

## Як працює програма — покроково

1. ESP-IDF запускає `app_main()` у main task; створюється лічильник зі значенням `0`.
2. `ESP_LOGI` друкує тег і повідомлення з поточним лічильником.
3. Лічильник збільшується, а задача робить паузу близько 1 s.
4. Цикл повторюється; інші задачі можуть працювати під час паузи.

`extern "C"` вимикає C++ mangling імені `app_main`, щоб стартовий код ESP-IDF
знайшов точку входу. `tag` — позначка джерела повідомлення в логу.
`app_main()` вже виконується в FreeRTOS main task: додаткова задача не потрібна.
`vTaskDelay` блокує цю задачу, дозволяючи іншим працювати; `pdMS_TO_TICKS`
перетворює мілісекунди на такти планувальника (ticks). Інтервал залежить від
частоти ticks, фази виклику та планування, тому це не точний секундний генератор.

## Відповідність Arduino ↔ ESP-IDF

| Arduino | ESP-IDF |
|---|---|
| `setup()` | Ініціалізація в `app_main()` |
| `loop()` | `while (true)` в `app_main()` |
| `Serial.println()` | `ESP_LOGI(tag, format, ...)` для логів |
| `delay(ms)` | `vTaskDelay(pdMS_TO_TICKS(ms))` |

Відповідності наведено за метою; параметри, типи результатів і семантика можуть відрізнятися.

## Запуск

У терміналі з активованим ESP-IDF, з каталогу цього проєкту:

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p COMx flash monitor
```

`set-target` потрібен при першій конфігурації; `COMx` замініть портом плати.
Вихід з monitor: `Ctrl+]`.

## Що студент повинен побачити або виміряти

Приблизно щосекунди з'являється
`Hello from ESP-IDF! Counter: 0`, потім `1`, `2`, … з тегом `hello_world`.
`uint32_t` задає розмір лічильника; `PRIu32` задає відповідний формат логування.

## Експерименти для самостійної роботи

Змініть `log_interval_ms` з `1000` на `250`, зберіть і прошийте знову.
Очікуйте приблизно чотири повідомлення за секунду.

Джерело: [FreeRTOS ESP-IDF 5.5.5](https://docs.espressif.com/projects/esp-idf/en/v5.5.5/esp32s3/api-reference/system/freertos_idf.html).

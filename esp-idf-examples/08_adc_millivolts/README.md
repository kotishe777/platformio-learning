# 08 — ADC: калібрування до mV

## Мета прикладу

Чому RAW не дорівнює фізичній напрузі.
Незалежний C++ ESP-IDF проєкт для ESP32-S3 DevKitC-1 / N16R8, API локального SDK **5.5.0**.
16 MB Flash; PSRAM вимкнена. Arduino Framework і PlatformIO не використовуються.

## Схема підключення

Потенціометр 10 kΩ: крайні контакти → 3.3 V і GND, повзунок → GPIO1 (ADC1_CH0). Не подавайте понад 3.3 V; верхня частина ходу може давати насичення ADC.

Плату підключіть USB-кабелем з даними. Стандартна консоль — через USB-to-UART роз’єм.
Перевірте GPIO за схемою своєї плати; цифрові сигнали мають рівні 3.3 V, не подавайте 5 V на GPIO.

## Нові функції ESP-IDF та їхні параметри

| API | Призначення та параметри |
|---|---|
| `adc_oneshot_new_unit(&config, &handle)` | Вибирає unit і повертає його handle через адресу; результат функції — esp_err_t. |
| `adc_oneshot_config_channel(handle, channel, &config)` | Задає бітність і ослаблення для каналу. |
| `adc_oneshot_read(handle, channel, &raw)` | Одне перетворення; код помилки повертається, RAW записується в int. |
| `adc_cali_create_scheme_curve_fitting(&config, &handle)` | Створює калібрування для тих самих параметрів ADC; може повернути ESP_ERR_NOT_SUPPORTED. |
| `adc_cali_raw_to_voltage(handle, raw, &mv)` | Перетворює RAW на калібровані мілівольти, результат функції — esp_err_t. |

Докладні пояснення структур, полів, результатів та порядку викликів є безпосередньо у `main/main.cpp`.
`constexpr` задає константи компіляції; `extern "C"` зберігає точку входу;
`ESP_ERROR_CHECK` перевіряє код помилки, не виміряне значення.
`vTaskDelay` блокує поточну task, дозволяючи працювати іншим; його аргумент — RTOS ticks.

## Як працює програма — покроково

1. Налаштувати oneshot ADC.
2. Створити curve fitting і обробити відсутність підтримки.
3. Читати RAW, за підтримки окремо калібрувати й друкувати mV.

RAW — цифровий код, не мілівольти. Для ESP32-S3 при ADC_ATTEN_DB_12 офіційний вимірюваний діапазон орієнтовно 0..3100 mV; 3.3 V живлення, діапазон ADC і гранично допустима напруга — різні поняття. Реальні коди мають похибку й нелінійність. Формула raw * 3300 / 4095 не замінює калібрування.

## Відповідність Arduino ↔ ESP-IDF

| Arduino / звичний підхід | ESP-IDF |
|---|---|
| `analogRead()` | adc_oneshot_read() |
| `analogReadMilliVolts()` | oneshot + adc_cali_raw_to_voltage() |

Це відповідності за метою; аргументи та семантика можуть відрізнятися.

## Що студент повинен побачити або виміряти

Лог містить raw та calibrated mV; за відсутності калібрування — лише RAW і явне повідомлення.
Це очікування для експерименту; роботу на реальній платі тут не перевірено.

## Експерименти для самостійної роботи

Виміряйте напругу повзунка мультиметром і порівняйте з mV у середині діапазону.

## Запуск

З цього каталогу в терміналі з активованим ESP-IDF:

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p COMx flash monitor
```

`set-target` — при першій конфігурації; `COMx` замініть портом плати. Вихід з monitor — `Ctrl+]`.
Стан перевірки всіх проєктів — у [загальному README](../README.md).
Офіційний довідник: [ESP-IDF 5.5 ESP32-S3](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32s3/index.html).
